# MATRIZ TÉCNICA DE LOS 185 CRITERIOS

**Estado:** matriz técnica cerrada para decisión y priorización el 23-09-2026, con pendientes normativos explícitos. No autoriza ejecución E2E, carga en base de datos ni tolerancias universales.

## Reglas de cierre

- Los 185 nombres, tipos y unidades provienen del catálogo base existente; no se han inventado tolerancias.
- `CONFIGURABLE POR PROTOCOLO/CLIENTE` significa que la fuente o el protocolo aplicable todavía no está verificado.
- Una opción preexistente no se convierte en regla normativa sin fuente, versión, mercado y protocolo asociados.
- La columna `Fuente` identifica el documento o el estado de asociación de cada fila; el catálogo de fuentes contiene documento, versión, fecha, mercado y alcance.
- `PENDIENTE-CHILE` no significa que el atributo sea inválido: significa que no se encontró un requisito chileno verificable para ese atributo.
- `REFERENCIA TÉCNICA` no es una tolerancia normativa automática; sus valores sólo pueden usarse si el mercado o protocolo los adopta.
- Cada fila tiene una acción concreta para el inspector aunque el método, instrumento o fuente permanezcan pendientes.
- Los campos normativos no definidos quedan explícitamente como `PENDIENTE DE ASOCIAR A FUENTE` o `NO DEFINIDO`.

## Muestreo: regla aplicable y limitaciones

- **QualityNX:** `10 muestras por 1.000 kg` es la regla operacional base definida por el producto. No tiene una fuente normativa SAG asociada y no debe presentarse como requisito oficial.
- **SAG SMR Arándano Chile→Paraguay (mayo 2026):** el documento usa 300 corimbos para prospección fitosanitaria, 150 plantas con 2 corimbos por planta, y para inspección oficial de lotes 1% de cajas cuando el lote tiene 1.000 cajas o más o 10 cajas cuando tiene menos. Su nivel de confianza declarado es 95% y la infestation objetivo inferior al 1%. Escala únicamente a Lobesia botrana y mercado Paraguay.
- **USDA AMS Blueberry Inspection Instructions (octubre 2002):** la referencia técnica usa 100 frutos o el envase completo si contiene menos de 100; 200 frutos si el envase no cumple el grado; 1% del lote con un mínimo de 3 muestras para embalajes de menos de 300. Es una regla de inspección de grado USDA, no una regla SAG ni la regla QualityNX.
- **UNECE FFV-57 y Codex CXS 349-2022:** son referencias internacionales de calidad, madurez, defectos y tamaño; no reemplazan el protocolo del mercado ni autorizan copiar tolerancias a la matriz QualityNX.
- Para cada mercado distinto de Paraguay debe existir un protocolo SAG/importador identificado antes de asignar una regla de muestreo o condición obligatoria.
